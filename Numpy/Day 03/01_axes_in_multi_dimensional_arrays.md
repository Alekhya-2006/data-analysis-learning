# NumPy

## Axes in Multi-Dimensional Arrays

- 1D Array → 1 Axis
  - axis 0 → elements in the array

- 2D Array → 2 Axes
  - axis 0 → rows (vertical direction)
  - axis 1 → columns (horizontal direction)

- 3D Array → 3 Axes
  - axis 0 → depth (layers)
  - axis 1 → rows within each layer
  - axis 2 → columns within each row
