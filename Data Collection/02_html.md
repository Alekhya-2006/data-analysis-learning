# HTML for Data Science

- HTML stands for HyperText Markup Language

- It is a Standard Language to create web pages and structure content on the web

- These web pages are structured using 'tags', which define elements like headings, paragraphs, links, tables, lists, and forms.

- When our page loads, our browser interprets HTML to display this content accordingly

- Html follows a hierarchial structure, so tahs can contain other tags
