# Web Scraping

Web scraping is the process of automatically extracting data from websites.

Popular Python libraries used for web scraping:

1. requests
   - Sends HTTP requests to websites
   - Downloads webpage content (HTML)

2. BeautifulSoup
   - Parses HTML/XML documents
   - Helps find and extract specific data from webpages
   - Best for static websites

3. Selenium
   - Automates a real web browser
   - Can interact with buttons, forms, scrolling, etc.
   - Useful for JavaScript-rendered (dynamic) websites
