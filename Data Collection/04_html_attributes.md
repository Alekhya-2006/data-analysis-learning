# Attributes in HTML

HTML elements can have attributes that provide additional information, metadata, or behavior.

- href  -> specifies the URL of a link in the <a> tag
- src   -> specifies the source URL of media such as images (<img>)
- id    -> unique identifier for a single HTML element
- class -> groups similar elements together (commonly used in CSS, JavaScript, and Web Scraping)
- type  -> defines the type of an input element in forms
- name  -> assigns a name to form elements for data submission
- value -> stores the value associated with a form element
